# にじみ帖

ブラウザで動く水彩・インク・鉛筆のお絵かきアプリです。1つの HTML ファイルだけで動き、インストールは要りません。

## 開き方

- **Web**：GitHub Pages で公開しています → https://omochi7777.github.io/nijimisuisai/
- **アプリとして使う（PWA）**：上のURLを開いて「ホーム画面に追加」すると、全画面・オフラインでも使えます
  - iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」
  - Android：Chrome のメニュー →「アプリをインストール」
  - PC（Chrome / Edge）：アドレスバー右の「インストール」アイコン
- **ローカル**：`index.html` をダブルクリックしても動きます（オフライン機能とインストールは HTTPS で開いたときだけ有効）

## 道具（キーボードショートカット）

| 道具 | キー | 内容 |
|---|---|---|
| 鉛筆 | P | 筆圧で濃くなり、ペンを寝かせると芯の腹で広く塗れます。粉は紙の凸部に乗ります。2H〜6B と色鉛筆を選べます |
| Gペン | G | 筆圧で線の太さが大きく変わります。マウスや指では、入りが自動で細くなります |
| 水彩筆 | B | 水と顔料を紙に置きます。乾く前に重ねると混ざってにじみ、縁に顔料がたまります。長いストロークでは筆の水が切れてかすれます |
| 平筆 | F | 幅の広い平らな穂先です。角度は固定なので、動かす向きで太い面にも細い線にもなります。回転を検知するペンなら回転に追従します |
| 墨筆 | S | 穂先の細い筆です。和紙を選ぶと繊維に沿ってにじみます |
| 水筆 | W | 水だけを置きます。濡れた色をのばしたり、半乾きの所に置くとバックラン（ブルーム）ができます |
| しずく | I | 絵の具をぽたりと落とします。押している間は滴り続けます。水筆で濡らした所に落とすと、枝分かれする筋を伸ばしながら広がります（筋の強さは「にじみの筋」） |
| ガッシュ | O | 不透明な絵の具です（丸筆と平筆）。白で光を入れたり、暗い色の上に明るい色を重ねられます。「かすれ」で筆跡の擦れ、「混色」で下の絵の具と混ざる量を変えられます |
| ティッシュ | T | 濡れた絵の具を吸い取ります |
| 消しゴム | E | ペンの消しゴム側（お尻）でも使えます |

- 元に戻す：Ctrl+Z ／ やり直す：Ctrl+Shift+Z または Ctrl+Y
- サイズ：`[` `]` ／ 画面に合わせる：`0` ／ ドライヤーで乾かす：`D`
- にじみの筋：濡れた紙に絵の具が入ったとき、枝分かれして伸びる筋の強さです（0%で筋なし、標準140%）。水彩系の道具のパネルと「紙と設定」にあります
- 乾く速さ：水彩系の道具のパネル、または「紙と設定」で 10%〜400% に変えられます。遅くすると、にじみが長く続きます
- 移動：上のバーの手のひらボタン（H）を押してからドラッグ、スペースを押しながらドラッグ、ペンのサイドボタン、ホイールボタン、右ドラッグ、2本指
- 拡大・縮小：上のバーの虫めがねボタン（+ / -）、Ctrl+ホイール、マウスホイール、ピンチ。％の数字を押すと画面に合わせます

## 画面の使い方

- 開くと最初に「紙を選ぶ」画面が出ます。紙の種類（中目・荒目・細目・和紙）と大きさを選んで始めます。「細かく設定する」で水の計算の重さ・にじみ・粒状感・乾く速さも選べます
- 描いている途中でも、上のバーの「新しい紙」から同じ画面を開けます。「紙の質感だけ変える」なら今の絵は残ります
- 色のパネルでは、色のセット（水彩・ポップ・レトロ・ビビッド・和の色）を切り替えられます

- 紙の右上の丸が、いま選んでいる色です。タップすると右から色とパレットのパネルが出てきます
- スマホでは、選んでいる道具をもう一度タップすると、太さや水の量などの調整が画面の中央に出ます（後ろの絵は透けて見えます）。外側をタップすると閉じます
- 「乾かす」ボタンは水位計になっています。中の水の高さが紙の濡れ具合で、青が濃いと「濡れています」、薄いと「しっとり（半乾き）」です。半乾きのときに水や絵の具を置くと、バックランや枝分かれのにじみが出やすくなります。押すとドライヤーで一気に乾かします
- 上のバーの半円のボタンで、表示を「自動・ライト・ダーク」の順に切り替えられます

## パレット

色のパネルの下にあるパレットで色を混ぜられます。

1. 色を選んで「置く」でパレットに絵の具を出します
2. 別の色も置いて「混ぜる」でなじませます（青と黄で緑になる減法混色。白を混ぜると淡くなります）
3. 「筆に取る」で、できた色をタップすると、その色で描けます

パレットの絵の具はブラウザに保存されるので、次に開いたときも残っています。「洗う」で空にできます。

## 白について

白（ホワイト）は道具ごとに効き方が変わります。

- 水彩筆・平筆・墨筆・しずく：濡れた色を淡くします（白を混ぜたような、ふんわりした明るさ）。白い紙の上では見えません
- ガッシュ：不透明な白で塗れます
- Gペン：ホワイトインクとして白い線が引けます
- 鉛筆（芯の硬さで「色」）：白い色鉛筆になります

## 保存

描いた絵は、この端末（ブラウザ）に1枚だけ自動で保存されます。次に開いたとき、最初の画面の「続きから描く」で戻れます。

- 新しい紙で描きはじめると、保存されていた絵は上書きされます
- 「設定」の「この端末の保存を消す」で消せます
- ブラウザのデータを消すと、保存も消えます。残したい絵は「画像を保存」でPNGにしてください
- 元に戻すの履歴は保存されません

## Wacom について

Windows では、ワコムタブレットのプロパティで「Windows Ink を使う」をオンにすると、ブラウザに筆圧が届きます。傾き（チルト）は鉛筆に効きます。

## 仕組み（メモ）

- WebGL2 で、紙の上の水の流れ、顔料の運搬・沈着、紙への浸透と乾燥をリアルタイムで計算しています。
- 色は透明水彩と同じく、吸光度を足し合わせる減法混色です。青と黄を重ねると緑になります。
- 紙の凹凸は手続き的に生成しています（中目・荒目・細目・和紙）。

## 今の制限

- ガッシュは不透明に重なりますが、濡れた水彩と混ざって溶ける表現（ガッシュを水で溶かす）はまだありません。
- 端末に保存できる絵は1枚だけです。
- 濡れた絵の具を計算するのは同時に1枚のレイヤーだけです。別のレイヤーに水彩を置くと、前のレイヤーの絵の具は乾いて定着します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体（HTML・CSS・JavaScript・シェーダーすべて入り） |
| manifest.webmanifest | PWAの設定（名前・アイコン・色） |
| sw.js | オフラインで動かすためのサービスワーカー |
| icon-*.png / apple-touch-icon.png | アイコン |
| LICENSE | ライセンス（MIT） |

## 更新するとき

index.html を変えたら、sw.js の `VERSION = 'nijimi-v3'` の数字を上げてから一緒にコミットしてください。インストール済みの端末が新しい版に入れ替わります。
