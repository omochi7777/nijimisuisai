# にじみ帖

ブラウザで動く水彩・インク・鉛筆のお絵かきアプリです。1つの HTML ファイルだけで動き、インストールは要りません。

## 開き方

- **Web**：GitHub Pages で公開しています → https://omochi7777.github.io/nijimisuisai/
- **アプリとして使う（PWA）**：上のURLを開いて「ホーム画面に追加」すると、全画面・オフラインでも使えます
  - iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」
  - Android：Chrome のメニュー →「アプリをインストール」
  - PC（Chrome / Edge）：アドレスバー右の「インストール」アイコン
- **ローカル**：`index.html` をダブルクリックしても動きます（オフライン機能とインストールは HTTPS で開いたときだけ有効）

## 道具（キーボードショートカット）

| 道具 | キー | 内容 |
|---|---|---|
| 鉛筆 | P | 筆圧で濃くなり、ペンを寝かせると芯の腹で広く塗れます。粉は紙の凸部に乗ります。2H〜6B と色鉛筆を選べます |
| Gペン | G | 筆圧で線の太さが大きく変わります。マウスや指では、入りが自動で細くなります |
| カリグラフィーペン | C | ペン先が平らなペンです。角度は固定なので、ペン先に沿って引くと細く、横切るように引くと太くなります。「ペン先角度」で変えられます（回転を検知するペンなら回転に追従）。不透明度を下げると、重ねた所だけ濃くなる透けたインクになります |
| 万年筆 | M | 細くなめらかなインクの線です。ペン先を止めて長押しすると、筆を押し付けたときの穂先のような形（書いてきた向きに先がとがる涙形）に、インクがじわりと滲み出します。滲む量は「にじみ」で変えられます |
| 水彩筆 | B | 水と顔料を紙に置きます。乾く前に重ねると混ざってにじみ、縁に顔料がたまります。長いストロークでは筆の水が切れてかすれます |
| 平筆 | F | 幅の広い平らな穂先です。角度は固定なので、動かす向きで太い面にも細い線にもなります。回転を検知するペンなら回転に追従します |
| 墨筆 | S | 穂先の細い筆です。和紙を選ぶと繊維に沿ってにじみます |
| 水筆 | W | 水だけを置きます。濡れた色をのばしたり、半乾きの所に置くとバックラン（ブルーム）ができます |
| しずく | I | 絵の具をぽたりと落とします。押している間は滴り続けます。水筆で濡らした所に落とすと、枝分かれする筋を伸ばしながら広がります（筋の強さは「にじみの筋」） |
| ガッシュ | O | 不透明な絵の具です（丸筆と平筆）。白で光を入れたり、暗い色の上に明るい色を重ねられます。「かすれ」で筆跡の擦れ、「混色」で下の絵の具と混ざる量を変えられます |
| ティッシュ | T | 濡れた絵の具を吸い取ります |
| 消しゴム | E | ペンの消しゴム側（お尻）でも使えます |

- 元に戻す：Ctrl+Z ／ やり直す：Ctrl+Shift+Z または Ctrl+Y（レイヤーの追加・削除も戻せます）
- スマホ・タブレット：2本指でタップすると1つ戻る、3本指でタップするとやり直し。「ペンだけで描く」にしているときは、指1本のダブルタップでも1つ戻ります
- サイズ：`[` `]` ／ 画面に合わせる：`0` ／ ドライヤーで乾かす：`D`
- にじみの筋：濡れた紙に絵の具が入ったとき、枝分かれして伸びる筋の強さです（0%で筋なし、標準140%）。水彩系の道具のパネルと「紙と設定」にあります
- 乾く速さ：水彩系の道具のパネル、または「紙と設定」で 10%〜400% に変えられます。遅くすると、にじみが長く続きます
- 移動：上のバーの手のひらボタン（H）を押してからドラッグ、スペースを押しながらドラッグ、ペンのサイドボタン、ホイールボタン、右ドラッグ、2本指
- 拡大・縮小：上のバーの虫めがねボタン（+ / -）、Ctrl+ホイール、マウスホイール、ピンチ。％の数字を押すと画面に合わせます
- 回転：上のバーの回転ボタン、`R`（右に15°）／ `Shift+R`（左に15°）、スマホは2本指でひねる（0°・90°付近で止まりやすくなっています）。回転中は上のバーに角度が出て、押すとまっすぐに戻ります

## 画面の使い方

- 開くと最初に「紙を選ぶ」画面が出ます。紙の種類（中目・荒目・細目・和紙）と大きさを選んで始めます。「細かく設定する」で水の計算の重さ・にじみ・粒状感・乾く速さも選べます
- 紙の色も選べます（紙のまま・生成り・クリーム・グレー・水色・桜・若草・藍・墨、ほかの色）。描いている途中でも「設定」から変えられます。濃い色の紙では透明な水彩や鉛筆は見えにくいので、ガッシュや白で描くのに向いています
- 描いている途中でも、上のバーの「新しい紙」から同じ画面を開けます。「紙の質感だけ変える」なら今の絵は残ります
- 描き始めてからでも、「設定」の「紙の大きさを変える」で紙の大きさを変えられます
  - **絵ごと拡大・縮小**：描いた絵も同じ割合で大きく・小さくなります（拡大すると少しぼやけます）
  - **紙を足す・切る**：絵はそのままで、紙を広げたり切り落としたりします。紙の上に新しい紙の枠が出て、□を動かすと大きさが、枠の中をドラッグすると位置が変わります（数値と連動）。広がる所は紙の色、切り落とされる所は暗く見えます。数値と、絵を置く位置（9か所）からも決められます
  - 大きさは1辺300〜2400px、全体で約432万画素（2400×1800 と同じ）までです。変えたあとでも「元に戻す」で、変更前の大きさと絵に戻せます
- 「設定」の「紙目を表示しない」で、紙の凹凸の陰影を消して平らな紙にできます（見た目と書き出す画像だけ。にじみ方は変わりません）
- 色のパネルでは、色のセット（水彩・ポップ・レトロ・ビビッド・和の色）を切り替えられます

- 紙の右上の丸が、いま選んでいる色です。タップすると右から色とパレットのパネルが出てきます
- スマホでは、選んでいる道具をもう一度タップすると、太さや水の量などの調整が画面の中央に出ます（後ろの絵は透けて見えます）。外側をタップすると閉じます
- 「乾かす」ボタンは水位計になっています。中の水の高さが紙の濡れ具合で、青が濃いと「濡れています」、薄いと「しっとり（半乾き）」です。半乾きのときに水や絵の具を置くと、バックランや枝分かれのにじみが出やすくなります。押すとドライヤーで一気に乾かします
- 上のバーの「傾き」で紙を傾けられます。丸の中の点を水を流したい方へ引っぱると、紙が濡れている間、水は低い方へ流れ続けます。絵の具やインクは水より少し遅れてねっとりと運ばれ、渦を巻きながら広がります。たまった水はやがて乾いた紙へあふれ出して垂れ、紙の端まで来た水は流れ落ちます。矢印キーでも傾けられます。スマホでは紙の左上に小さなパッドが出るので、絵を見ながら傾けられます
- 紙の左下の「ノート」（または N キー）で技法ノートが開きます。乾き具合・技法・画材・紙・ことばの章に分かれていて、本物の水彩の画材や技法の説明を読めます
- 上のバーの半円のボタンで、表示を「自動・ライト・ダーク」の順に切り替えられます

## 色の選び方

- **最近使った色**：実際に塗った色が、新しい順に6色まで並びます。押すとその色に戻ります
- **お気に入り**：今の色の横の ☆ で登録、もう一度押すと外れます（36色まで）。色のセットの並びの「★お気に入り」で、登録した色だけを一覧できます
- **色を作る**：「サークル」（外側の輪で色合い、内側の四角で鮮やかさと明るさ）、「スライダー」（色相・鮮やかさ・明るさ、色コードの入力）、「混色パレット」を切り替えられます。今の色の横の四角からは、ブラウザの色選びも使えます

最近使った色とお気に入りは、ブラウザに保存されます。

## パレット

「色を作る」の「混色パレット」で、絵の具を混ぜて色を作れます。

1. 色を選んで「置く」でパレットに絵の具を出します
2. 別の色も置いて「混ぜる」でなじませます（青と黄で緑になる減法混色。白を混ぜると淡くなります）
3. 「筆に取る」で、できた色をタップすると、その色で描けます

パレットの絵の具はブラウザに保存されるので、次に開いたときも残っています。「洗う」で空にできます。

## 白について

白（ホワイト）は道具ごとに効き方が変わります。

- 水彩筆・平筆・墨筆・しずく：濡れた色を淡くします（白を混ぜたような、ふんわりした明るさ）。白い紙の上では見えません
- ガッシュ：不透明な白で塗れます
- Gペン：ホワイトインクとして白い線が引けます
- 鉛筆（芯の硬さで「色」）：白い色鉛筆になります

## 保存

描いた絵は、この端末（ブラウザ）の**作品一覧**に自動で保存されます。何枚でも残せます。

- 開いたときの最初の画面に、いちばん新しい作品と作品一覧が並びます。描いている途中は、上のバーの「にじみ帖」（スマホではロゴ）を押すと作品一覧が開きます
- 作品を押すと「開く」「複製する」「削除する」を選べます。削除は確認のあとで消え、元に戻せません。描いている作品は削除できません
- 「選んで削除」で、いくつかの作品をまとめて削除できます
- 新しい紙にしても、今の絵は作品一覧に残ります。何も描いていない紙は作品一覧に入りません
- 上のバーの「保存」を押すと、今の絵が保存済みかどうかと、作品一覧・使っている容量が見られます
- 端末の空き容量が足りないなどで保存できなかったときは、「保存」の画面に「最新の変更を保存できていません」と出ます。その状態でほかの作品・新しい紙・ファイルに切り替えようとすると確認が出るので、.nijimi ファイルで保存してから進んでください
- ブラウザの設定で端末に保存できないときも、描いた絵があれば切り替える前に同じ確認が出ます。.nijimi ファイルに保存したあとは確認なしで進めます
- 作品の名前は「保存」の画面で付けられます
- 「設定」の「この端末の作品をすべて消す」で、まとめて消せます
- ブラウザのデータを消すと、作品も消えます。ほかの端末からは見られません。大事な作品は .nijimi ファイルにもしておくと安心です
- 元に戻すの履歴は保存されません

### どの保存がいい？

| 保存のしかた | 向いていること | 気をつけること |
|---|---|---|
| 作品一覧（自動） | 何もしなくても描くたびに保存。何枚でも、続きから描ける | ブラウザのデータを消すと消える。ほかの端末からは見られない |
| .nijimi ファイル | レイヤーごと保存。バックアップ、ほかの端末に移す、人に渡す | 開けるのはにじみ帖だけ。保存するたびに新しいファイルになる |
| PNG 画像 | 1枚の絵として。SNS・印刷・ほかのアプリで使う | レイヤーは残らず、続きは描けない |

### ホーム画面に追加する

公開版（GitHub Pages）では、最初の画面と「設定」に「ホーム画面に追加」の案内が出ます。追加すると、アプリのように全画面・オフラインで使え、作品もブラウザに消されにくくなります。Chrome・Edge・Android は「追加する」ボタンから、iPhone・iPad は Safari の共有ボタン →「ホーム画面に追加」から追加できます。

### ファイルに保存する・開く

上のバーの「保存」から、2通りで保存できます。

- **PNG画像**：1枚の絵として保存します
- **にじみ帖のファイル（.nijimi）**：レイヤー（名前・表示・不透明度・重ね順）、紙の種類と模様、濡れている絵の具ごと保存します。「新しい紙」→「ファイルを開く」で、続きから描けます。保存するときにファイル名を付けられます（開いたファイルは、次も同じ名前で保存できます）

.nijimi の大きさの目安（紙「横」1600×1200）：空のレイヤーは約15KB、線画は数百KB、紙全面を塗ったレイヤーは約6MBです。濡れている絵の具は乾いた状態で保存されます。

### 画像を読み込む

レイヤーの「画像を読み込む」で、PNG・JPG などの画像を新しいレイヤーとして、紙に収まる大きさで真ん中に置けます（元に戻せます）。

- **透明に重ねる**：白い所が透けます。線画や下絵をなぞるのに向いています
- **不透明に置く**：写真などをそのまま見せます。下のレイヤーは隠れます

置く前に、プレビューを見ながら調整できます。

- **紙の色を抜く**：スキャンや写真で紙の地に色がついている絵は、いちばん多い明るい色を地の色とみなして白にします。「透明に重ねる」と地が透け、線と色だけがこの紙に乗ります
- **明るさ・コントラスト**：地を白にしたあと、線を濃くしたいときなどに使います

### レイヤーを動かす・大きさを変える

レイヤーの「移動・拡大」（または V キー）で、選択中のレイヤーを動かせます。画像を読み込んだ直後も、このモードになります。

- ドラッグで移動、四隅のつまみ・Ctrl+ホイール・2本指のピンチで拡大縮小（縦横の比率は変わりません）。矢印キーで1ピクセルずつ（Shiftで10ピクセル）動かせます
- 上のバーの「確定」（Enter）で決まり、「やめる」（Esc）で元に戻ります。確定したあとも元に戻せます
- 濡れている絵の具は、乾かして定着させてから動かします
- 水彩の粒状感は紙の凹凸に合わせて描かれているので、大きく動かしたり拡大したりすると、粒と紙の凹凸がずれて見えることがあります。拡大するとぼやけます

「新しい紙」→「ファイルを開く」で画像を選ぶと、選んだ紙と大きさで新しく始めて、その画像を置きます。このアプリで書き出したPNGも読み込めますが、1枚の画像になり、紙の陰影も画像に入っているため、続きを描くなら .nijimi を使ってください。

## Wacom について

Windows では、ワコムタブレットのプロパティで「Windows Ink を使う」をオンにすると、ブラウザに筆圧が届きます。傾き（チルト）は鉛筆に効きます。

## 仕組み（メモ）

- WebGL2 で、紙の上の水の流れ、顔料の運搬・沈着、紙への浸透と乾燥をリアルタイムで計算しています。
- 色は透明水彩と同じく、吸光度を足し合わせる減法混色です。青と黄を重ねると緑になります。
- 紙の凹凸は手続き的に生成しています（中目・荒目・細目・和紙）。

## 今の制限

- ガッシュは不透明に重なりますが、濡れた水彩と混ざって溶ける表現（ガッシュを水で溶かす）はまだありません。
- 濡れた絵の具を計算するのは同時に1枚のレイヤーだけです。別のレイヤーに水彩を置くと、前のレイヤーの絵の具は乾いて定着します。
